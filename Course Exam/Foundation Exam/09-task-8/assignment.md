Create a new user and assign the user the **Ruleset Manager** role.

Scope the **Ruleset Manager** role to:

- Environment: `Production`
- Location: `ca`

The **Ruleset Manager** permissions must be limited to this scope and
must **not** apply to the entire organization.

> [!NOTE]
> Leave the user's default **Viewer** role with its **All** scope
> unchanged. Add the scoped **Ruleset Manager** role alongside the
> existing **Viewer** role.
