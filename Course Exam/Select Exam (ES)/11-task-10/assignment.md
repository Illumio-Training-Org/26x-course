La cuenta de AWS ya ha sido incorporada a Illumio Cloud
automaticamente en segundo plano (region **us-east-1**).

Crea una Application Discovery Rule usando Cloud Tags, que coincida
con la clave de tag `app`, con Auto Approve habilitado, para incorporar
la aplicacion que se ejecuta en esa cuenta.
