📝 Aufgabe
==========

Erstellen Sie eine IP List mit dem Namen `remote-office`.

Konfigurieren Sie die IP List mit:

- IP-Adresse: `45.54.45.0/24`
- Ausschluss: `!45.54.45.254`

Prüfen Sie, ob sowohl das Netzwerk als auch der Ausschluss korrekt
konfiguriert sind.
