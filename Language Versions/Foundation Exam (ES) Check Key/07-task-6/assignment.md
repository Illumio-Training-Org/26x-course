📝 Tarea
==========

Crea una IP List llamada `remote-office`.

Configura la IP List con:

- Dirección IP: `45.54.45.0/24`
- Exclusión: `!45.54.45.254`

Comprueba que tanto la red como la exclusión están configuradas
correctamente.

📝 Task (English)
==========

Create an IP List named `remote-office`.

Configure the IP List with:

- IP Address: `45.54.45.0/24`
- Exclusion: `!45.54.45.254`

Verify that both the network and exclusion are correctly configured.
