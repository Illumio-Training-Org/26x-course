📝 Tarea
==========

Crea un Service llamado `Redis`.

Configura el Service con:

- Protocolo: **TCP**
- Puerto: `6379`

Comprueba que el Service está disponible para usarlo en una policy.

📝 Task (English)
==========

Create a Service named `Redis`.

Configure the Service with:

- Protocol: **TCP**
- Port: `6379`

Verify that the Service is available for use in policy.
