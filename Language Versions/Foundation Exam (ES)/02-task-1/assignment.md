📝 Tarea
==========

Crea un nuevo Pairing Profile con su Enforcement Mode configurado en **Idle**.

Usa el nuevo Pairing Profile para emparejar el workload `linux-vm`
proporcionado y comprueba que el workload se conecta correctamente a
la plataforma de gestión.

📝 Task (English)
==========

Create a new Pairing Profile with its Enforcement Mode set to **Idle**.

Use the new Pairing Profile to pair the provided `linux-vm` workload
and verify that the workload is successfully connected to the
management platform.
