📝 Tarea
==========

Crea un Label Group llamado `pci-staging`.

El Label Group debe contener las dos labels de Environment
siguientes:

- `PCI`
- `Staging`

Comprueba que el Label Group está disponible para usarlo en una policy.

📝 Task (English)
==========

Create a Label Group named `pci-staging`.

The Label Group must contain both of the following Environment
labels:

- `PCI`
- `Staging`

Verify that the Label Group is available for use in policy.
