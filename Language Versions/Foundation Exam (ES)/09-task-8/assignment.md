📝 Tarea
==========

Crea un nuevo usuario y asígnale el rol **Ruleset Manager**.

Limita (scope) el rol **Ruleset Manager** a:

- Environment: `Production`
- Location: `ca`

Los permisos de **Ruleset Manager** deben limitarse a este scope y
**no** deben aplicarse a toda la organización.

> [!NOTE]
> Deja sin cambios el rol **Viewer** predeterminado del usuario con su
> scope **All**. Añade el rol **Ruleset Manager** con scope junto al rol
> **Viewer** existente.

📝 Task (English)
==========

Create a new user and assign the user the **Ruleset Manager** role.

Scope the **Ruleset Manager** role to:

- Environment: `Production`
- Location: `ca`

The **Ruleset Manager** permissions must be limited to this scope and
must **not** apply to the entire organization.

> [!NOTE]
> Leave the user's default **Viewer** role with its **All** scope
> unchanged. Add the scoped **Ruleset Manager** role alongside the
> existing **Viewer** role.
