📝 Tarea
==========

Incorpora (onboard) la cuenta de AWS proporcionada a Illumio.

> [!IMPORTANT]
> Durante la incorporación, configura la integración de AWS para usar
> la región: `us-east-1` (N. Virginia).

Completa el proceso de incorporación y usa el Map para confirmar que
el nuevo recurso de AWS aparece correctamente.


> [!NOTE]
> Es posible que los flujos de tráfico todavía se estén cargando en
> este momento. Si es así, continúa sin usar el Map.
