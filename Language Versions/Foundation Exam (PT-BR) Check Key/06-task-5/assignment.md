📝 Tarefa
==========

Crie um Label Group chamado `pci-staging`.

O Label Group deve conter as duas labels de Environment a seguir:

- `PCI`
- `Staging`

Verifique se o Label Group está disponível para uso em policy.

📝 Task (English)
==========

Create a Label Group named `pci-staging`.

The Label Group must contain both of the following Environment
labels:

- `PCI`
- `Staging`

Verify that the Label Group is available for use in policy.
