📝 Tarefa
==========

Crie uma IP List chamada `remote-office`.

Configure a IP List com:

- Endereço IP: `45.54.45.0/24`
- Exclusão: `!45.54.45.254`

Verifique se a rede e a exclusão estão configuradas corretamente.

📝 Task (English)
==========

Create an IP List named `remote-office`.

Configure the IP List with:

- IP Address: `45.54.45.0/24`
- Exclusion: `!45.54.45.254`

Verify that both the network and exclusion are correctly configured.
