📝 Tarefa
==========

Crie um novo usuário e atribua a ele a função **Ruleset Manager**.

Defina o scope da função **Ruleset Manager** como:

- Environment: `Production`
- Location: `ca`

As permissões de **Ruleset Manager** devem ficar limitadas a este scope e **não** devem se aplicar à organização inteira.

> [!NOTE]
> Mantenha inalterada a função padrão **Viewer** do usuário, com o scope **All**.
> Adicione a função **Ruleset Manager** com scope junto com a
> função **Viewer** existente.

📝 Task (English)
==========

Create a new user and assign the user the **Ruleset Manager** role.

Scope the **Ruleset Manager** role to:

- Environment: `Production`
- Location: `ca`

The **Ruleset Manager** permissions must be limited to this scope and
must **not** apply to the entire organization.

> [!NOTE]
> Leave the user's default **Viewer** role with its **All** scope
> unchanged. Add the scoped **Ruleset Manager** role alongside the
> existing **Viewer** role.
