📝 Tarefa
==========

Crie um novo Pairing Profile com o Enforcement Mode definido como **Idle**.

Use o novo Pairing Profile para parear o workload `linux-vm` fornecido e verifique se o workload está conectado com sucesso à plataforma de gerenciamento.

📝 Task (English)
==========

Create a new Pairing Profile with its Enforcement Mode set to **Idle**.

Use the new Pairing Profile to pair the provided `linux-vm` workload
and verify that the workload is successfully connected to the
management platform.
