Supon que el workload Web ha sido comprometido.

Marca `linux-vm` como comprometido cambiando su label de DFIR:

`IR-CLEANBUBBLE` → `IR-DIRTYBUBBLE`

Asegurate de que el workload ya no conserve el label
`IR-CLEANBUBBLE`.
