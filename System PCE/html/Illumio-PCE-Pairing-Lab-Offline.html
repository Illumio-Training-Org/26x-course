Offline pairing lab
  1. Go to Servers & Endpoints → Pairing Profiles. Open Default (Servers), or select Add to create your own profile.
  2. Select Generate Key. The Pairing Key page shows the profile's initial workload settings, a key and the pairing scripts.
  3. Copy the Linux OS Pairing Script. If copying is blocked, the script is selected for you: press Ctrl+C or ⌘C.
  4. Select Workload terminal in the bottom strip, choose linux-ven-01, paste the script at the prompt and press Enter.
  5. Watch the VEN install and pair, then run illumio-ven-ctl status.
  6. Open Servers & Endpoints → Workloads and inspect the new workload.
